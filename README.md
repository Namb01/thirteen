# Tiến Lên (Thirteen)

A browser card game: play against computer players, or with friends in an online room.

## Run it locally

Two terminals (on Windows PowerShell, use `npm.cmd` instead of `npm` if scripts are blocked):

```bash
npm run server   # game server for online rooms, http://localhost:3001 (WebSocket /ws)
npm run dev      # the site, http://localhost:5173 (forwards /ws to the server)
```

"Play vs computer" works without the server; creating or joining a room needs it.
To try multiplayer alone, open the site in two browser tabs: each tab is a separate player.

## Production

```bash
npm run build    # builds the site into dist/
npm start        # one server for both the site and the game (PORT env var, default 3001)
```

## Project layout

```
src/
  main.tsx, App.tsx   entry point; App switches between the screens
  screens/            Home (start screen), LocalGame (vs computer), Online (room + online game)
  components/         GameTable (the table and your hand), CardFace, cardArt (card image paths)
  styles/             base.css (colors, buttons), table.css (game screen), lobby.css (start/room screens)
  game/               rules (cards, combos, engine), computer player (ai), timing. Shared with the server
  net/                protocol (browser ↔ server messages), useServer (connection)
server/               lobby.ts (rooms and online games), index.ts (WebSocket + web server)
public/cards/<size>/  card images the game loads, generated by scripts/resize-cards.py
art/                  original card deck (source for the script) and CREDITS.md
```

To change the card art, replace the files in `art/cards/` and run `python scripts/resize-cards.py` (needs Pillow).

## Checks
